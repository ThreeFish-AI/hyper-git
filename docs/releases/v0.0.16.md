# Hyper Git - Agentic Git v0.0.16 — 多根工作区仓库切换 · 分支分组树 · Agentic Git 预置

> 本版是自 v0.0.14 以来的全量积累（0.0.15 版本号已就位但未单独发布，本版一并发布）。四大新特性：**多根工作区多仓库切换**、**Branches 按前缀分组树**、**Agentic Git 偏好配置与 Claude Code 配置预置**（M5 前置铺垫），并修复新增 / 删除 / 重命名文件打不开差异的问题、优化面板默认布局。

---

## ✨ 亮点速览

- **多根工作区多仓库切换**：Graph 工具栏仓库名成为**可切换按钮**，一键在多根工作区的多个仓库间切换全局活跃仓库——Graph / Branches / Commit / Stash / Shelf / Worktrees / 未提交角标**七视图级联跟随**，且 changelist、分支收藏、Shelf、最近提交消息、视图状态全部**按仓库隔离记忆**，重开窗口回到上次操作的仓库。
- **Branches 按前缀分组为文件夹树**：Local / Remote / Tags 三段支持「平铺 ⇄ 树」切换，共享前缀的分支收拢为可折叠文件夹（如 `feature/1.x.x`、`feature/2.x.x` → 📁`feature`），远程整体收拢为 `origin` 文件夹；默认树形、偏好按仓库记忆。
- **Agentic Git 预置（M5 前置铺垫）**：新增 `hyperGit.agent.*` 四项偏好（PR 基线分支 + Commit / Create PR / Review 三项 agent 指令模板）与 `hyperGit.claudeCode.executablePath` 设置（留空自动探测 `claude`）+ 「浏览 / 打开 Claude 设置」快捷入口。
- **Diff 修复**：新增 / 删除 / 重命名文件在 Commit 与 Graph 视图可正常打开差异（空树 ref 构造 URI），修复重命名点击崩溃。
- **面板布局优化**：Commit / Branches / Graph / Worktrees 依序默认呈现（前两者折叠），Stash / Shelf 默认隐藏（可经视图右键菜单恢复）。

## 🧩 特性详述

### 1. 多根工作区仓库切换（#108 / issue #107）

此前在含多个 Git 仓库的多根工作区中，Hyper Git 只能操作单一仓库。本版将 Graph 工具栏仓库名升级为**可切换按钮**（对标 Git Graph；单仓库退化为纯文本，多数用户零感知），Command Palette 亦可经 `Hyper Git: Select Repository…` 直达。

- **七视图级联**：切换后 Graph / Branches / Commit（changelist）/ Stash / Shelf / Worktrees / 未提交角标全部跟随新活跃仓库刷新；
- **按仓库隔离记忆**：changelist 分配、分支收藏、分组偏好、Shelf 存储（旧平铺数据一次性安全迁移：仅 rename、零删除零覆盖）、最近提交消息、Graph / Commit 视图状态（scope / 选中 / 勾选集）均按仓库分区；
- **持久化**：活跃仓库记于 `workspaceState`，重开窗口回到上次操作的仓库。

### 2. Branches 按前缀分组树（#86）

Local / Remote / Tags 三段支持在**平铺**与**按 `/` 前缀分组的可折叠文件夹树**间切换（工具栏按钮，偏好按仓库持久化、默认树形）。共享前缀的分支收拢到以前缀命名的文件夹下、叶子仅显示末段后缀；远程整体收拢为 `origin` 文件夹。排序分支感知：当前 HEAD → 收藏 → 同档文件夹优先、名称数字感知升序；并**隐藏 `origin/HEAD` 符号引用**（对齐主流 Git UI）。checkout / delete / rename / merge / rebase / compare / favorite 等右键操作全部不受影响。

### 3. Agentic Git 预置（#88 / #89，M5 前置铺垫）

- **偏好配置**：`hyperGit.agent.baseBranch`（创建 PR 的基线分支，留空=仓库默认分支）+ `commitPreferences` / `createPrPreferences` / `reviewPreferences`（点击 **Commit / Create PR / Review** 时发送给 agent 的自定义指令，多行文本域、内置默认模板）；
- **Claude Code 配置**：`hyperGit.claudeCode.executablePath`（留空=从 `PATH` 自动探测 `claude`）+ 命令 `Set Claude Code Executable Path…`（QuickPick 浏览写回）与 `Open Claude Settings`（打开 `~/.claude/settings.json`，缺失时经确认创建）。

以上为配置层预置，`agent/` 接缝与 `hyperGit.ai.enabled` 行为不变、零破坏。

### 4. Diff 缺失端修复（#87 / issue #15）

新增文件（无旧端）、删除文件（无新端）此前在新版 VS Code 上打不开差异（`readFile` 对不存在具名 ref 抛 `FileNotFound`）。本版改用 git **空树 ref** 构造 URI，跨 VS Code 版本稳定解析为空内容；重命名文件两端异路径正确呈现；同时修复 Graph 视图点击重命名文件崩溃的问题。

### 5. 面板默认布局调整（#101 / issue #16）

六视图默认态微调：**Stash / Shelf** 默认隐藏（经视图标题右键菜单勾选恢复）、**Commit / Worktrees** 默认折叠、**Branches / Graph** 默认展开，顺序调整为 Commit · Branches · Graph · Worktrees。

## ⚙️ 升级与兼容

- **无破坏性变更**：全部特性均为增量新增或纯修复，未移除任何命令 / 配置 / 视图。
- **布局默认仅影响新安装 / 干净 profile**：VS Code 会记忆旧布局——老用户升级后如需采用新默认，请执行命令面板「View: Reset View Locations」或右键 Hyper Git 容器页签「Reset Location」（平台行为，同 [issue #12](../.agents/issue.md)）。
- **多仓库数据迁移安全**：Shelf 旧平铺数据迁移仅 rename，零删除零覆盖。
- **开发者**：包管理器升级 pnpm 11.9.0 → **12.2.1**（Rust 重写版，命令 / 配置 / 锁文件格式兼容 pnpm 11）；CI 自动跟随，克隆后 `pnpm install` 即可。

## 📦 安装

- **VS Code Marketplace**：搜索 `Hyper Git - Agentic Git` 直接安装或更新。
- **手动**：从 [Releases](https://github.com/ThreeFish-AI/hyper-git/releases/tag/v0.0.16) 下载 `hyper-git-agentic-git-0.0.16.vsix` → 命令面板 `Extensions: Install from VSIX`（Cursor / Windsurf / VSCodium 等用户可经此方式安装）。

**系统要求**：VS Code ≥ 1.85.0，且启用内置 Git 扩展（`vscode.git`，默认随附）。仅支持本地 git 仓库，不支持虚拟 / Web 工作区。
