# Hyper Git - Agentic Git v0.0.9-rc.2 — 浮层定位修复

> ⚠️ **Release Candidate**：本版本是 0.0.9 的第二个候选版，聚焦修复 [v0.0.9-rc.1](./v0.0.9-rc.1.md) 中 Log 视图浮层的定位问题。完整特性集同 rc.1。

## 🔧 本版修复

### Log 提交/CI 浮层定位重做（不再撑满侧边栏）

rc.1 中，提交悬浮详情与 CI 状态浮层被锚定在所悬元素的**左沿**、并按 webview 宽度夹紧。在 ~240px 的窄侧边栏里，420px 宽的浮层从侧边栏左沿一路铺到编辑器，既「撑满 LOG 视图」又方位怪异。

rc.2 改为：
- **横向**：固定到 `window.innerWidth + 8`——即侧边栏右沿外 8px、编辑器区内，浮层整体浮在 LOG 视图右侧，不再压住提交列表。
- **纵向**：与所悬行/图标顶部对齐，按视口高度夹紧（超出下沿自动上移）。
- 复用 webview `position:fixed` 可越界渲染到编辑器区的特性，浮层自然悬浮于所悬行的右侧，贴近原生 tooltip 体验。

CI 状态浮层（`positionTip`）与提交详情浮层（`positionCommitTip`）同步应用该定位逻辑。
