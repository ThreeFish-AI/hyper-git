# Hyper Git - Agentic Git v0.0.23 — 本地分支 PR 状态徽标 · 开发依赖升级

> 本版核心：Branches 视图的 PR 状态徽标从远程分支**扩展到本地分支**——Local Branches（含 Favorites 本地条目与活动分支）行右侧以与远程行一致的形态显示关联 GitHub PR（`#N Merged/Open/Closed/Draft`），一眼看清哪条本地分支的 PR 已合并、可安全删除；非活动分支图标按 PR 状态着色，悬停同样可见 PR 号 / 标题 / Open on GitHub。

---

## ✨ 亮点速览

- **本地分支行 PR 徽标**：Local Branches 每行右侧显示关联 PR（`#138 Merged` 形态与远程行一致），Favorites 中的本地条目与当前活动分支同样生效（活动分支呈 `active #138 Merged`，状态由徽标文本承载）；
- **图标按状态着色**：非活动本地分支的分支图标按 PR 状态着色——Merged 紫 / Closed 红 / Open 绿 / Draft 弱化；活动分支蓝、收藏黄优先于 PR 状态色，与既有视觉语义零冲突；
- **宁缺勿错的匹配语义**：本地裸分支名走「同仓 Tier b → 唯一兜底 Tier c」——多 fork 同名分支产生歧义时不显示，绝不展示错误 PR；不剥 remote 前缀、不做 fork 身份匹配（本地名不携带 remote 身份），本地名 `origin/feature` 只匹配字面同名的 PR；
- **零新增请求、零取数改动**：完全复用远程行既有的 GraphQL 取数链路（最近更新的全态 PR 列表、TTL 缓存、限流退避），本地行匹配为预计算索引上的 O(1) 查询，配置开关（`hyperGit.branches.pr.enabled`）与静默边界（未登录 / 非 GitHub 仓 / 配置关闭 → 零徽标零请求）不变。

## 🧩 特性详述

### 1. Branches 视图本地分支 PR 状态徽标（#158）

- **覆盖范围**：Local Branches 分组全部本地分支、Favorites 中的本地条目、当前活动分支（HEAD）；远程分支行行为与 v0.0.22 完全一致，零回归；
- **匹配语义**：远程短名沿用三级匹配（fork 全名身份校验 → 同仓 → 唯一兜底）；本地**裸分支名**只走后两级——按完整裸名先匹配同仓 PR（headRefName 精确相等），无命中且全库同名候选唯一时兜底显示该 PR（`gh pr checkout` / fork 工作流场景）；歧义（多 fork 同名）与掉出最近 100 条 PR 的旧分支静默无徽标。不用 `ref.upstream` 参与匹配，消除 API / CLI 双数据路径下的徽标闪烁；
- **预期分歧**：本地名形如 `owner/branch`（fork checkout 形态）不参与 fork 身份匹配——本地行无徽标而对应远程行可经身份校验有徽标，属有意设计（本地名不携带 remote 身份，无法安全校验）；
- **实现锚点**：engine 层 `RemotePrIndex` 更名 `BranchPrIndex` 并新增 `lookupLocal` 入口（同一份预计算索引、双查询入口），增量与全量单测覆盖；详见[功能文档](../features/branches-pr-status.md)。

## 📦 安装

- **VS Code Marketplace**：搜索 `Hyper Git - Agentic Git` 直接安装或更新。
- **Open VSX**：搜索 `Hyper Git - Agentic Git` 直接安装或更新（覆盖 Cursor / Windsurf / VSCodium 等 Open VSX 系编辑器）。
- **手动**：从 [Releases](https://github.com/ThreeFish-AI/hyper-git/releases/tag/v0.0.23) 下载 `hyper-git-agentic-git-0.0.23.vsix` → 命令面板 `Extensions: Install from VSIX`。

**系统要求**：VS Code ≥ 1.85.0，且启用内置 Git 扩展（`vscode.git`，默认随附）。仅支持本地 git 仓库，不支持虚拟 / Web 工作区。
