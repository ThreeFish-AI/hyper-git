# Hyper Git - Agentic Git v0.0.21 — Filter by Author 候选建议 · 多选过滤 · 元字符作者修复

> 本版核心：**Graph 视图「Filter by Author…」从「裸输入框完整手输单个作者名」升级为「候选建议 + 多选」**。候选列表来自仓库真实提交作者（`git shortlog` 按当前视图范围取数、按提交数降序）——输入 `Thr` 即在下拉中建议 `ThreeFish`，姓名与邮箱均可模糊匹配，点选即填、无需手输完整 ID；依次勾选多个提交者即可按作者集合过滤 Graph 视图（OR 语义）。同时修复了作者名含正则元字符（如 `dependabot[bot]`）时过滤 0 命中的隐性缺陷。

---

## ✨ 亮点速览

- **前缀输入提示**：在过滤输入框键入姓名或邮箱前缀，下拉即时给出匹配的提交者（附提交数与邮箱），点选即选中——不再要求人工完整输入作者名。
- **多选过滤**：依次勾选任意多个提交者，Graph 视图立即按所选作者集合过滤（任一命中即保留）；空选确认 = 清除作者过滤，Esc = 取消不改。
- **正则逃生口**：输入不等于任何作者姓名时，下拉头部动态提供「Use pattern "xxx"」项——手输任意正则原样透传，旧输入框的任意 pattern 能力完整保留，且可与选中身份混用（OR）。
- **元字符作者修复**：`dependabot[bot]` 这类含 `[ ] . +` 的作者名此前按正则原样传递导致 0 命中；现在从候选选中的身份按字面精确匹配（BRE 转义 + 全行锚定 `Name <email>`，同名异邮箱不混淆）。

## 🧩 特性详述

### 1. 作者候选建议与多选（#149）

- **候选取数**：`git shortlog -sne` 按当前 Graph 视图 scope（All / Current / Checkpointer）取真实提交作者，按提交数降序、附邮箱——候选与视图所见范围一致，切换 scope 后重开即同步；
- **多选语义**：多个作者翻译为多条 `git log --author`（git 原生取 OR）；与 Message / Path / Date / Merge 等其它过滤维度仍为 AND 组合，`Clear Graph Filter` 一键全清；
- **交互细节**：等待取数期间显示 busy 且可先输入；已勾选项在继续键入过滤时保持不丢；再次打开时预勾选当前已过滤的作者，便于增删；空仓库 / 查询失败时降级为仅 pattern 输入（近似旧行为）。

### 2. BRE 字面转义修复（#149）

- `git log --author` 的 pattern 缺省按 POSIX BRE（Basic Regular Expression）解释：`dependabot[bot]` 中的 `[bot]` 是字符类、`.` 匹配任意字符——作者名原样传递即偏离字面语义，含 `[ ]` 的作者 0 命中、含 `.` 的作者可能误伤他人；
- 修复：从候选选中的作者身份按 BRE 语义转义（仅 `\ . [ * ^ $` 有特殊义；`+ ? | ( ) {` 在 BRE 中本就是普通字符，勿加反斜杠）并首尾锚定 `^Name <email>$` 全行匹配——精确身份、同名异邮箱不混淆（本仓库实测：`dependabot[bot]` 修复前 0 命中、修复后 36 命中）。

## ⚙️ 升级与兼容

- **无破坏性变更**：全部既有命令、视图与配置项保留；其它过滤维度（Message / Path / Date / Merge / Regex）行为与组合语义与 v0.0.20 一致；
- **行为改进**：作者过滤条件仅存于内存（切换仓库自动清空，不持久化），升级后无遗留状态迁移问题；手输任意正则的能力经「Use pattern」项完整保留。
